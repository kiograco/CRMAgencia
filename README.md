
  # Wireframe Cruise Intelligence CRM

  This is a code bundle for Wireframe Cruise Intelligence CRM. The original project is available at https://www.figma.com/design/7NQqsOMaB5ZcHxuVCBp0iR/Wireframe-Cruise-Intelligence-CRM.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  The frontend uses `/api` by default and the Vite dev server proxies requests to `http://127.0.0.1:3000`. Keep the backend running on port `3000` before logging in.
